Integrações de envio

Os botões Enviar para edição e Enviar para design mandam os dados do conteúdo (cliente, roteiro, pasta do Drive) para estes endereços (webhook). Seu agente de edição pode recebê-los por n8n, Make, Zapier ou um servidor próprio. Sem endereço, o conteúdo só é marcado como "na fila" e o briefing é copiado para você colar.
